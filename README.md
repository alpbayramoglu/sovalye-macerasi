# Şövalye Macerası

Bomba bırakıp labirentte ilerlenen bir çocuk oyunu. 8 dünya × 8 bölüm; her dünyanın 8. bölümü boss.
Tek dosya: `index.html` (kodla çizim, dış bağımlılık yok). Oyna: https://alpbayramoglu.github.io/sovalye-macerasi/

- **Kontroller:** Bilgisayarda ok tuşları / WASD ve boşluk. Telefonda sol yarıda parmağın değdiği yerde joystick, sağ yarıya dokunmak bomba.
- **Sayı Bahçesi:** Aynı dosya `sayi-bahcesi/sovalye/` altına kopyalanır; o yolda her bölüm 1 bilet, bölüm +2, boss +5 altın. Başka yerde biletsiz.
- **Sürüm:** `index.html` içindeki `VERSION` (v0.x) ve aynı adlı git etiketi.
- Haritalar, karakterler ve adlar bu projeye ait.
